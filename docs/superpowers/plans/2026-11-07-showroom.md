**Goal:** Ship a distinctive exhibition homepage and a practical independent catalog for the existing 24 templates.

**Tech Stack:** Next.js 16, React 19, TypeScript, native CSS, GSAP, @gsap/react, Phosphor.
**Spec:** ../specs/2026-11-07-showroom-design.md
