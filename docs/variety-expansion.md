## 浏览与修改

目录新增“产品工具”“生活方式”“文化活动”分类。保留中英文搜索、收藏及大屏三列、中屏两列、手机一列的等宽排列。分类较多时工具栏自动换行；窄屏分类可以横向滚动。

模板入口位于 `src/kits/<slug>/Template.tsx`，内容集中在 `content.ts`，样式在有作用域的 `theme.css`，设计规则在 `DESIGN.md`。主题保持各自品牌方向，不跟随平台深色主题改变。运行 `npm run build` 同步生成下载包和配色数据；目录封面来自真实浏览器截图。

任务、菜单、节目、空间和搜索演示均在浏览器内运行。品牌、角色与项目是虚构模板内容。联系按钮复制明确标记的 `.example` 邮箱，不发送消息。平台收藏与反馈仍保存于访客浏览器。
