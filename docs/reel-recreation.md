# 回映 REEL：光盘画廊

回映是形集 FORME 的第 22 套模板，提供光盘集、映像详情和关于三个页面，包含六份原创的虚构影集提案。预览入口为 `/preview/cinema`，模板介绍为 `/templates/cinema`，独立下载为 `/downloads/cinema.zip`。

## 参考与实现范围

用户指定的参考为 [Ravi Klaassens 的 A24 Television 实验](https://a24.raviklaassens.com/television)。实际查看了桌面、手机、索引、翻面和详情画面。重新实现了浅灰颗粒画布、角落作品资料、居中导航、斜向三维光盘轨道、相邻光盘的画外裁切、中心孔、金属边缘、背面虹彩和索引预览。

这是对上述 UI 构图和交互的重新实现，未宣称像素级一致。参考站的图片、片名、文字、品牌标志、字体文件和源码没有纳入项目。回映的片名与文案为原创虚构内容；替换摄影沿用本项目已有的 Unsplash 素材。逐项地址、字体许可和技术来源见 [SOURCES.md](../SOURCES.md#回映-reel-交互复刻)。光盘封面由照片与原创 Canvas 排字组成；颗粒纹理和背面 GLSL 着色器为本项目生成或编写。

## 操作

| 操作 | 结果 |
|---|---|
| 滚轮、水平拖动、触摸滑动 | 沿轨道切换光盘 |
| 点击当前光盘、翻转按钮 | 切换封面与金属背面 |
| 聚焦画廊后按方向键、Home、End | 浏览、首张、末张 |
| 聚焦画廊后按空格、Enter | 翻面、进入当前映像 |
| 双击当前光盘、查看映像按钮 | 进入当前映像详情 |
| 打开索引，悬停或聚焦条目 | 预览对应光盘；点击进入详情 |
| Escape | 关闭索引并恢复触发按钮焦点 |
| 暂停动态 | 停止持续摆动；切换与翻面即时完成 |
| 详情页展开画面 | 从三图网格切换为纵向大图 |
| 返回光盘集 | 恢复查询参数所标识的作品 |

手机将导航放到底部，缩小邻盘以突出当前光盘。联系操作只复制标明为示例的邮箱，不发送消息。

## 配置与兼容

编辑 `src/kits/cinema/content.ts` 可以替换品牌、六份影集内容、摄影路径，以及光盘大小、轨道、阻尼和纹理尺寸。主题变量集中在 `theme.css`，渲染独立放在 `Scene.tsx`。

Three.js 在进入光盘画廊后延迟加载。连续输入和渲染状态保存在场景闭包中，React 只处理作品选择等离散状态。像素比上限为 1.6，封面纹理为 1024×1024，仅绘制附近光盘。页面隐藏或离开视口时暂停绘制；卸载时释放纹理、材质、几何体、监听器和渲染器。

系统开启减少动态效果时不持续摆动。WebGL 初始化失败或上下文丢失时显示静态光盘，保留按钮切换、翻面和详情入口。备用视图不包含真正的三维透视和金属着色器效果。

独立下载包通过 `dependencies.json` 声明 `three` 和 `@types/three`，版本从平台 `package.json` 读取。导出器包含同目录额外的 `.ts/.tsx/.css` 源文件，确保 `Scene.tsx` 一并交付；既有模板没有增加 Three.js 依赖。
