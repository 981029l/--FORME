# 序列 CHAPTER

面向时装编辑、艺术指导与独立创作者的虚构作品集。首页建立视觉识别，项目页展示一组概念影像的编辑逻辑，关于页说明服务与工作方法。

## 视觉计划

- 色彩：纸页粉 `#f2e5e6`、勃艮第红 `#541d30`、灰玫瑰 `#79545f`、浅纸白 `#fbf5f4`、装订线 `#d6bcc2`。
- 字体：Georgia / 宋体负责大标题的编辑感；本地 Manrope 负责英文辅助文字；中文正文使用系统黑体。
- 版式：宽幅 CHAPTER 刊头下是左大右小的封面跨页，右侧文字与小幅人像构成杂志侧栏。项目页先展开单张人物影像，再以两张不同尺度的图版展示编辑顺序。关于页用文字主导的扉页和服务目录建立独立节奏。
- 识别动作：刊头、封面阅读顺序与图版编号共同模拟一本正在展开的时装杂志；编号对应同一概念系列的阅读顺序，不充当虚构业绩。

```
品牌                         导航
          C H A P T E R
刊号                         编辑方向
大幅人物封面          项目标题
大幅人物封面          小幅图版
图版说明              阅读入口
            编辑观点
横向图版              系列说明
```

## 内容与来源

「序列」与「柔软的秩序」均为虚构演示内容。人物、服装及摄影画面来自项目共享的外部摄影素材，素材作者与许可信息由 FORME 根目录的来源记录统一维护。页面仅展示视觉编辑与作品集编排，不把素材摄影归为工作室原创，不虚构客户、奖项或商业成果。

## 实现边界

仅依赖 React、`content.ts` 与公共页面类型。所有样式限定在 `.kit-fashion`；颜色、字体、间距与过渡时长集中在根级主题变量。三个页面共享导航与标明用途的演示邮箱复制交互，支持跳过导航、键盘焦点、当前页面提示和减少动态效果。390px 与 360px 采用纵向封面阅读顺序，不隐藏内容修补溢出。

## 验证记录

作者执行了隔离的 TypeScript 严格检查（`--noEmit`），结果通过。React 服务端渲染检查覆盖三种页面与两种 `basePath`，确认每页只有一个主标题、正文区域、首张急加载图片和当前导航状态，站内路径与锚点有效，图片文件存在且具备尺寸与替代文本。PostCSS 成功解析 158 条限定作用域的规则。实际浏览器、复制交互、构建与导出验证由主任务统一执行，避免并行修改共享产物。
