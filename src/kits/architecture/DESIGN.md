# 构间 MONO

这是面向建筑与空间研究事务所的虚构作品集。视觉采用白灰底、石墨文字、精确的细线与宽幅城市影像；大尺度无衬线标题和紧凑项目索引表达建筑的秩序感。设计参数为变化 6、动效 2、密度 3，动效仅承担链接反馈。

首页以完整宽幅建筑影像开场，接图文研究索引与事务所观点。项目页「之间计划」包含概念简报、城市／居住／景观三个可定位章节和工作方法。关于页说明研究立场、服务尺度与协作方式。研究内容均为虚构概念，不包含真实客户、建成业绩或性能声明。

字体、色彩、边距与动效时长集中在 theme.css 根变量中；文案、导航、邮箱、素材路径及图片尺寸集中在 content.ts 中。保留现有本地 Manrope 字体，并为中文设置系统无衬线字体回退。整体使用固定的白灰色主题，以符合选定的视觉方向。

移动端将图文列、项目章节和服务区域依次堆叠；360px 下缩小英文字标并保留四个导航入口。页级容器不使用 overflow 隐藏溢出。所有路由共享跳过链接、当前页提示、联系区、可见焦点、邮箱复制失败反馈和减少动效支持。图片声明固有尺寸，每页首图 eager，其余 lazy。

摄影为外部公开图库素材，沿用项目公共 assets 及素材来源清单；并非 MONO 设计或拍摄的建筑。页面项目末尾明确说明该素材用途。建筑与室内照片已本地查看，替代文字只描述可见内容。

在独立下载包中，先阅读 README.md 与 AGENTS.md。页面契约位于 app/kits/types.ts，文案与样式位于 app/kits/architecture/。摄影与字体来源见 SOURCES.md。修改后运行 npm run build，并检查三个页面的桌面与手机布局、导航和联系操作。
