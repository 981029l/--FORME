# 海岸 TIDELINE

面向旅行影像编辑与纪实摄影作品集的虚构品牌。以海面到红色岩地的视觉过渡为单一概念系列，首页呈现远景与阅读入口，项目页给出图像组织方法，关于页说明纪实编辑的工作原则。

## 视觉计划

- 色彩：海图白 `#f3f6f2`、深海蓝 `#173d4e`、雾蓝 `#4b6770`、浅海灰 `#e4eceb`、图注白 `#ffffff`。
- 字体：本地 Manrope 用于品牌与英文标签；Georgia / 宋体用于中文叙事标题；系统黑体用于日记正文与图注。
- 版式：首屏是横跨页面的海景，文字落在有渐变承托的下方；之后以宽松的双页手记和不等宽图像恢复纸页阅读。项目页用全幅风景建立尺度，再用侧栏图注和长文解释编辑过程。关于页从大段留白和横向景观开始。
- 识别动作：一条贯穿首页的蓝色岸线阅读条，把“海面—地平线—旷野”三个实际叙事章节连在一起；不编造经纬度、旅行日期或真实拍摄经历。

## 内容与来源

「海岸」与「海与旷野」为虚构演示品牌及概念系列。海面与红色台地摄影来自 FORME 共享的外部素材，作者和许可由根目录来源记录维护。文字说明图像编辑、阅读顺序和风景观察，不声称摄影由虚构工作室创作，也不杜撰真实旅程、地点、客户或成果。海景没有沙滩或岩岸；荒漠画面为岩石台地与岩丘，并非沙丘，图注与替代文本均按实际素材内容描述。

## 实现边界

所有 CSS 以 `.kit-travel` 为作用域，颜色、排版、间距集中在主题变量。仅使用 React、公共类型与本地内容数据。三页共享导航、跳转到正文、当前页面状态与演示邮箱复制。图片使用固定尺寸和加载提示，图注保留素材边界；移动端将跨页转换为连续手记，完整保留所有内容。

## 验证记录

作者执行了隔离的 TypeScript 严格检查（`--noEmit`），结果通过。React 服务端渲染检查覆盖三种页面与两种 `basePath`，确认每页只有一个主标题、正文区域、首张急加载图片和当前导航状态，站内路径与锚点有效，图片文件存在且具备尺寸与替代文本。PostCSS 成功解析 194 条限定作用域的规则。主任务负责统一浏览器、构建、复制交互及导出验证。没有将未执行的测试写成通过。

浏览器检查发现浅海灰底板上的原辅助文字色对比度不足，统一将 `--td-muted` 从 `#54727b` 加深为 `#4b6770`。按 WCAG 相对亮度公式计算，新色在海图白底上的对比度为 5.55:1，在浅海灰底上为 5.04:1，均超过普通文字 4.5:1 的要求。修改后的浏览器复核由主任务执行。
