# 暗场 NOIR

暗场是虚构演示工作室。“光的切面”为概念影像编辑，使用公开授权素材；不宣称这些照片为工作室原创，不包含虚构摄影师、客户或奖项。

## 视觉系统

固定近黑背景、灰白文字和灰度摄影。色彩、字体、边距与过渡速度在 `.kit-gallery` 自定义变量中集中管理。英文 NOIR 大字作为影像索引入口，照片采用错位展陈，留白为图像提供观看距离。首页、影像详情、关于页均有完整内容；不通过装饰性编号模拟展览档案。

排版变化 8、动态 4、密度 3。只有可点击图片的轻微缩放与链接箭头位移，没有自动轮播、滚动劫持或初始隐藏内容。图片的灰度处理是本套视觉语言，替换彩色素材后仍保持统一。

## 内容与功能

- 内容、邮箱、图片路径和替代文字统一编辑 `content.ts`。
- 首页只有“光的切面”承担项目跳转；另外两幅图片是影像索引中的非交互展品，不伪装成可点击项目。
- 导航以 `basePath` 组合，独立导出传入空字符串；`page` 支持 `home`、`project`、`about`。
- 联系区复制 `.example` 演示邮箱。复制失败提供手动复制提示，没有真实发送动作。

## 修改边界

CSS 必须保持 `.kit-gallery` 作用域。不要添加彩色 CTA、卡片背景、模糊玻璃或渐变。照片保留宽高、替代文字与加载策略。手机端将展陈改为单列，通过左右留白保留节奏；保留键盘焦点与减少动态支持。
