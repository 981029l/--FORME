# 回映 REEL

## 设计来源与范围

交互与构图参考 Ravi Klaassens 的 [A24 Television 实验](https://a24.raviklaassens.com/television)：浅灰颗粒画布、斜向 3D 光盘轨道、翻面反光、角落作品资料、居中索引、手机底部导航。页面、着色器和光盘封面均重新编写；不使用该站图片、片名、文案、标志、字体文件或源代码。

原创品牌为回映 REEL，六个作品是虚构的影集提案。封面使用本项目已有 Unsplash 摄影加原创排字，素材出处见 SOURCES.md。文案、日期与媒介均为概念设定，不代表真实电影或奖项。

## 视觉规则

- 固定浅灰纸面、黑色排字与照片颜色；不增加渐变按钮、圆角卡片或营销区块。
- UI 使用本地 Manrope 和系统中文字体；展示字使用系统 Georgia / 宋体回退。字体不从参考站复制。
- 首页固定一屏，主角是沿斜线运动的实体光盘；左右相邻光盘保留画外裁切。手机主盘缩小、邻盘后退，导航移到底部。
- 正文只在作品页和关于页展开；首页两段文字是原创观看笔记，不能改成虚构媒体评价。
- DESIGN_VARIANCE 9、MOTION_INTENSITY 8、VISUAL_DENSITY 3；连续渲染和指针状态在 Three.js 闭包内，React 只处理当前作品和离散 UI 状态。

## 文件与运行

- content.ts 管理品牌、摄影、片名、正文、交互文案与场景参数。
- Template.tsx 管理三页、索引、文字、联系复制与无 WebGL 视图。
- Scene.tsx 是延迟载入 Three.js 的渲染组件，负责网格、原创纹理、着色器与输入。
- theme.css 只使用 .kit-cinema 作用域。
- dependencies.json 声明独立下载所需的 three 与 @types/three，版本从平台 package.json 读取。

## 行为

滚轮、水平拖动、触摸滑动与方向键切换光盘；点击当前光盘或空格翻面，Enter、双击或查看映像按钮进入作品页。索引可通过键盘进入，Escape 关闭并恢复触发点焦点。作品页保留查询参数，返回光盘集恢复相应作品。

减少动态效果和暂停按钮停止持续摆动，切换即时完成；页面隐藏或离开视口时停止动画帧。像素比上限 1.6，光盘纹理 1024 像素，只绘制附近光盘。卸载时释放纹理、几何体、材质、事件与 WebGL 渲染器。无 WebGL 时仍保留封面、翻面、切换和详情入口。
