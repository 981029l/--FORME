# 噪点 OFFBEAT

音乐活动与独立文化集体的三页概念模板，使用洋红底色、紧凑黑体和现场摄影形成音乐海报的张力。品牌、艺人及节目都是虚构演示内容。

## 设计判断

面向独立音乐听众，以音乐海报为视觉母体，采用原生 CSS 与 React。DESIGN_VARIANCE 为 8，MOTION_INTENSITY 为 3，VISUAL_DENSITY 为 5。固定品牌色覆盖整页，不因系统深色模式改变。高饱和洋红与强字重是任务明确要求；动效仅用于交互反馈，不自动播放、不滚动劫持。

- 洋红 `#f747a1`、近黑 `#191317`、深莓辅助文字 `#351522`、分隔线 `#bc397d`。
- 中文大字采用系统黑体，英文采用 Arial Black / Arial；时间与辅助字段用 Courier New 回退系统黑体。无额外在线字体请求。
- 首页由错位的两行标题与人群照片构成，日期横条承接到大字号艺人编排；内容结构不是商品卡片。
- 节目页使用日期按钮、声音类型选择器和可展开的节目介绍；空筛选有明确恢复动作。
- 关于页采用宽幅人群照片、文化集体宣言与开放的工作范围目录。
- 全部组件保持直角，使用线条分组。320px 起切为单列，节目保留紧凑时间轴，导航完整可见。

## 交互与可访问性

三页导航支持当前页面提示，提供跳过导航。日期按钮使用 `aria-pressed`，类型选择器有可见标签，结果数量以状态区域反馈。每场介绍采用原生 `details` / `summary`，可用键盘打开。演示邮箱按钮复制到剪贴板，失败时显示手动复制文案；不发送邮件。焦点清晰，图片具有实际尺寸与替代文本，减少动态效果偏好会关闭过渡与位移。

## 内容与来源

摄影来自共享素材 `/assets/concert.jpg`，展示人群和飘落的纸屑，并非虚构艺人的演出照片。页面文案不将摄影归属于品牌活动。具体图片来源、作者和许可由 FORME 根目录 `SOURCES.md` 统一维护。全部可见文字、图片配置与节目数据集中在 `content.ts`，颜色及尺寸集中在 `.kit-music` 主题变量中。

## 独立导出

只依赖 React、`content.ts` 与 `../types.ts`。`basePath` 为空时三页路径为 `/`、`/project`、`/about`；支持放入 FORME 预览路径。模板所有 CSS 都限定在 `.kit-music` 下，无平台路径别名、额外依赖或运行时网络图片。
