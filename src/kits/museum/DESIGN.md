# 观物 MUSE

围绕日常器物、生活记忆与公共交流展开的虚构文化机构模板。三页分别承载展览入口、完整策展提案和机构空间介绍。

## 设计判断

面向文化展览读者，以中文展签和策展出版物为视觉母体，使用原生 CSS 与 React。DESIGN_VARIANCE 为 6，MOTION_INTENSITY 为 2，VISUAL_DENSITY 为 3。任务明确指定宋体、朱红与近白，因此采用固定纸页主题；不随系统深色偏好改变展览识别。

- 近白底 `#faf9f6`、朱红标题 `#a42c20`、中性正文 `#35312d`、辅助文字 `#6e655e`、分隔线 `#dbd5ce`。
- 中文标题使用 Songti SC / STSong / SimSun，英文标志使用 Palatino 字族；正文使用系统黑体。传统衬线呼应展签与文化出版语境，不依赖在线字体。
- 首页采用两列竖排中文标题与横向展厅照片；竖排是中文阅读结构，不是旋转的英文装饰。展览事实条、器物研究图版和公共活动在其后展开。
- 策展页以明确的研究路径组织三个单元，桌面侧栏提供页内目录；手机恢复普通文档流。章节图片、观察问题与论述对应真实内容。
- 关于页提供三种空间的用途选择，切换后显示参与方式；原生问答折叠块补充阅读背景。
- 全部为直角与细线，照片下说明解释用途；无卡片阴影、滚动劫持或自动动效。

## 内容与来源

`museum-room.jpg` 为1600×1260博物馆摄影，展示玻璃展柜与肖像画；`ceramics.jpg` 展示浅色陶瓷器皿；`pottery.jpg` 展示木台面的盘碗；`stilllife.jpg` 展示灰绿色墙面前的落地灯。素材作为空间与器物研究参考，不认定为观物馆藏，不为其虚构年代或作者。真实来源与许可记录由 FORME 根目录 `SOURCES.md` 维护。

## 可访问性与实现

文本、图片、目录、空间数据和状态文案集中在 `content.ts`。CSS 全部限定于 `.kit-museum`，主题值集中在根变量。导航有 `aria-current`，提供跳过导航；三空间按钮有 `aria-pressed` 与关联区域，区域变化可被辅助技术感知；问答使用原生 `details`。邮箱复制有成功与失败状态，不发送消息。320px 起有明确布局，减少动态效果会取消过渡。

## 独立导出

仅依赖 React、`content.ts` 和 `../types.ts`，不导入平台组件。`basePath` 为空或预览前缀都能正确导航。四个模板文件与被引用图片即可进入独立导出包。浏览器视觉检查、交互测试与完整打包由主任务集中完成。
