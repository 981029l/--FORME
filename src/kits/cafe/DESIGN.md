# 慢调 SLOWBAR

面向社区咖啡馆与饮食品牌的复古网站概念。固定砖红与淡黄色、厚重 Georgia 字标、中文宋体标题、双线菜单分隔和方角控件，共同构成有烟火气的老式咖啡馆语言。首页以占满横向的大字标与低位咖啡照片建立记忆点，随后切换为可操作的菜单，再展开街角小店的故事。设计参数：变化 7、动效 2、密度 4。版面与拾器的居中器物摄影不同；不用柔焦阴影、通用功能卡或滚动劫持。

首页包含三个分类的风味菜单，按钮使用 aria-pressed 和 aria-controls，当前分类通过独立的礼貌实时区域播报。咖啡手记页包含器具、三段冲煮步骤、口味调整和配方计算器。粉量为 15 / 20 / 30 克，粉水比为 1:15 / 1:16 / 1:17；注水量等于粉量乘以比例，闷蒸水量约为粉量的两倍且计入总量。数值是家用尝试起点，不是商品性能承诺。关于页说明店铺概念及三个日常原则。菜单与空间均为虚构品牌演示，不提供下单、订位或营业地址。

文案、菜单数据、默认值、选项和图片声明统一在 content.ts；色彩、字体、间距及交互时长统一在 theme.css 的 --sb-* 根变量。CSS 只作用于 .kit-cafe。控件采用方角，原则编号的圆形只表达编号；不存在混合的卡片圆角体系。使用系统 Georgia、中文宋体与中文无衬线回退，不新增字体或库。固定明亮主题来自本套品牌要求。

三页复用带 aria-current 的导航、单一 main 和 h1、跳过链接及页脚联系区。演示邮箱为 hello@slowbar.example，复制成功与失败均给出可访问反馈，失败时可直接选择可见邮箱。移动端收拢装饰字标、全部多列段落改为单列，保留三页导航与完整互动。320px 起适配，不通过隐藏页面溢出来掩盖问题。仅链接位移承担操作反馈，并尊重减少动态效果设置。

已人工检查本地素材内容：coffee.jpg 为 1600×2400，三杯咖啡与盆栽的竖幅照片；cafe-room.jpg 为 1600×1097，含木椅、绿植与黑板的咖啡馆空间。两者为主项目提供的图库素材，不是慢调出品或店铺实拍，版权来源保留于公共 SOURCES.md。首页咖啡图片裁取纵向中下部，避免裁掉前景咖啡杯；店铺照片保持空间线索。

独立包内先读 README.md、AGENTS.md。在 app/kits/cafe/content.ts 修改品牌与配方，在 theme.css 调整主题。不要拆出打包器未收集的依赖文件。修改后运行 npm run build 并检查首页菜单、咖啡页粉量与比例、三页导航及邮箱复制；桌面、768px、390px 与320px 均需检查。
