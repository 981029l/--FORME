# 青屿 VERDANT

面向植物生活、苗圃内容与空间创作的虚构工作室。固定浅薄荷与深叶绿，采用已有 Manrope 与中文无衬线字体，整体清新、易读。首页以左侧两行大标题和右侧高拱形蕨叶近景为中心，接入光照选择器，再用养护工具照片与横向叶片窗口展开生活故事。设计参数：变化 7、动效 2、密度 3。大幅绿色摄影、曲线窗口和实用照顾内容是本套的识别点，避免套用陶瓷作品集的衬线标题与器物陈列。

首页与绿意手记页提供真实可用的光照选择器：明亮散射光、少量晨光、离窗较远。选择后同步更新观察建议、三个养护步骤及当前条件；控件采用 aria-pressed、aria-controls 和实时结果区域，支持原生键盘焦点。低光选项明确先改善光照，不宣称植物可以无光生长。项目页为完整窗边植物角概念，包含光照、形态层次、器皿和三个原生 details 养护问答；关于页说明空间提案、内容编辑和影像叙事范围。

文案、图片、光照选项与演示资料集中在 content.ts；主题、字体、间距、圆角和交互速度统一在 theme.css 的 --vd-* 变量。CSS 作用域是 .kit-botanical。图文面板使用20px圆角，操作按钮使用胶囊，摄影窗口使用拱形或椭圆裁切，形状按功能区分而非任意混搭。固定明亮主题来自本套绿植品牌方向。仅原生 React 状态，不新增依赖、外部接口或动画库。

三页含单一 main 与 h1、跳过链接、完整导航和 aria-current，保留可见键盘焦点。邮箱 hello@verdant.example 仅用于复制演示；成功与失败反馈通过状态区域播报，失败时可选择可见地址手动复制。移动端所有多列板块转换为单列，首页导航始终可见，320px 起适配。不使用页面级 overflow 隐藏布局问题，图片圆角的局部裁切仅服务视觉。按钮位移和问答符号状态尊重减少动态效果。

已查看真实素材：leaves.jpg 为1800×2699的绿色蕨叶近景，用于表现叶片形态；botanical.jpg 为1600×1067的绿色园艺铲、剪刀、土壤和小花盆照片，用于养护主题。图库素材不代表青屿完成的项目或售卖的植物。具体图库来源与许可保留在主项目 SOURCES.md。不要把工具照片误写成盆栽空间全景，也不要将野外蕨叶照片当作室内落地案例。

独立下载包先阅读 README.md、AGENTS.md，再修改 app/kits/botanical/content.ts 与 theme.css。保持模板页契约与四个文件的打包边界。修改后运行 npm run build，验证三页导航、三个光照状态、养护问答和邮箱复制，并检查桌面、768px、390px、320px、长中文文案及减少动态效果。
