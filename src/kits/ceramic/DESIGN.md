# 拾器 TERRE

这是面向陶瓷与器物创作者的虚构作品集。设计围绕象牙纸色、陶土色、宋体与 Georgia 衬线体、居中标题及内嵌摄影展开。字、图和留白的节奏更接近一本安静的器物手记。设计参数为变化 6、动效 2、密度 2；低动效保留阅读与观看的节奏。

首页用居中的两行标题与带侧注的器物照片开场，随后呈现日常宣言、釉色摄影与器物手记入口。项目页「土色系列」说明概念性质，包含器形、釉色、日用三个锚点与提案过程。关于页介绍观察立场、创作范围和协作方法。品牌、项目及服务叙事均属虚构，不包含真实工艺生产或商业业绩声明。

色彩、字体、间距与交互时长由 theme.css 根变量统一管理；所有文案、链接标签、演示邮箱和带固有尺寸的图片声明集中在 content.ts。使用现有本地字体环境与中文宋体系统回退，不增加远程字体或依赖。固定象牙纸色主题来自既定陶作方向。

桌面以居中字标和两侧导航形成对称秩序。移动端保留所有导航入口，移除非必要侧注，器物照片与文字按阅读顺序堆叠。页级布局不以 overflow 隐藏溢出。所有页面含单一主标题与 main、跳过链接、当前页面标记、可见焦点、复制邮箱失败反馈和减少动效支持。

ceramics.jpg 和 pottery.jpg 均由主任务提供，为公开图库摄影。已本地检查：前者是浅色架上的乳白与砂点器皿，后者是木台面上的蓝色和深色盘碗。图片尺寸均为 1600×1067，替代文字描述真实内容。项目页明示它们不是拾器制作或拍摄的实物，具体来源沿用项目公共素材清单。

在独立下载包中，先阅读 README.md 与 AGENTS.md。页面契约位于 app/kits/types.ts，文案与样式位于 app/kits/ceramic/。摄影与字体来源见 SOURCES.md。修改后运行 npm run build，并检查三个页面的桌面与手机布局、导航和联系操作。
