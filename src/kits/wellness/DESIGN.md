# 余息 EASE

日常轻运动工作室概念，面向希望轻松开始活动的人。以柔和粉杏与深玫瑰色、圆润字形、上方跨栏标题和下方错位圆角照片形成运动海报感。设计参数：DESIGN_VARIANCE 8 / MOTION_INTENSITY 3 / VISUAL_DENSITY 3。

## 页面与视觉

- 首页首屏为十二栏海报构图：跨栏中文标题、圆形海面照片、偏右的大幅伸展摄影，左下留给简短文案与课程入口。不是常规左右均分首屏。
- 课表采用实色底、圆角容器与清楚的时间层级；整周与单日筛选均为真实按钮，练习类型使用原生选择器。
- 练习页有独立完整内容，三种练习均包含时长、准备物品、三个阶段与动作提醒。
- 关于页以椭圆海面照片、品牌理念、理想空间参考与圆润字牌收尾。
- 固定浅色主题，所有 CSS 作用于 `.kit-wellness`。基础颜色、字体、间距与圆角集中为 `--ea-*` 变量。
- 系统圆润字体回退到 Trebuchet MS 与中文系统黑体，无远程字体依赖。微动仅用于按钮反馈，不增加自动播放或持续动画。

## 可用行为

- 首页默认周一、全部类型，显示两场练习。按天与类型组合筛选，结果数量实时宣告。
- 周日无课程；任意空组合显示清楚的空状态和“查看全部安排”，该按钮将两个筛选都恢复为整周/全部类型，共八场。
- 笔记页切换基础活动、舒展流动、静坐收尾后同步更新完整练习说明，阶段分钟数与总分钟数对应。
- 每场活动仅为示例课表，不显示虚假预约或购买按钮。
- 复制邮箱使用 `hello@ease.example`，成功状态与失败后手动复制提示可被辅助技术读取，不发送邮件。
- 文案与示例数据全部在 `content.ts`。运动内容为一般轻活动，不承诺医疗、康复或特定效果。

## 响应与无障碍

每页一个 `h1` 和 `main`，跳至正文、三页当前导航、原生控件与可见焦点完整。桌面八个日子按钮一行，767px 以下为四列两行，避免水平滚动。手机首屏按标题、照片、文案顺序排列。练习笔记在移动端变为单列，320px/390px 的字级与间距有显式调整。状态文字对比使用深玫瑰色，控件不以图标替代可见标签；减少动态设置移除全部过渡。

## 来源

品牌、课表与文案为本模板原创示例。`wellness.jpg` 是海边日落中的伸展人物剪影，不代表工作室课程；`coast.jpg` 与 `interior.jpg` 是自然和空间参考。摄影来源及许可见交付包 `SOURCES.md`。交互使用 [React useState](https://react.dev/reference/react/useState)、[原生选择器](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/select) 与 [HTML details](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/details)。
